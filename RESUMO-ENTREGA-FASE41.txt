Padrão OBSERVER:

    TAMQPServer                 User Handler
    │                           │
    ├─ Subscribe(Handler)  ←────┤
    ├─ Unsubscribe(Handler) ←───┤
    └─ NotifyEvent(Event)
         │
         ├─ [Snapshot handlers + release lock]
         │
         └─ Call each handler async
              │
              └─ Handler runs independently
                 └─ Exception isolated

Garantias:
   ✓ FIFO order: eventos preservam ordem por thread
   ✓ Thread-safe: Subscribe/Unsubscribe sincronizadas
   ✓ Non-blocking: handlers rodam fora do lock
   ✓ Fault-isolated: exceção não afeta outros
   ✓ Zero overhead: sem subscribers = zero custo

│ EXEMPLO MÍNIMO                                                               │
└──────────────────────────────────────────────────────────────────────────────┘

procedure OnAMQPEvent(const E: TAMQPServerEvent);
begin
  case E.EventType of
    seMessageDelivered: RecordConsumption(E);
    seMessageAcked: MarkAsUsed(E);
    seMessageExpired: Alert(E.QueueName + ' expirou');
  end;
end;

procedure Start;
begin
  FServer := TAMQPServer.Create;
  FServer.Subscribe(OnAMQPEvent);
  FServer.Start;
end;
